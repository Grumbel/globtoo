# Globtoo for R36S (ArkOS)

Copy `Globtoo.sh` and the `globtoo/` folder into `ports/` on the game card,
or put `globtoo.zip` in `ports/PortMaster/autoinstall/` and open PortMaster.

| Button | Action |
| --- | --- |
| D-pad | Move the pointer |
| A | Click or hold to drag |
| L1 / R1 | Zoom out / in |
| Start | Exit |

The launcher writes `globtoo/log.txt`. License and asset credits are included
in the port's `share/doc/globtoo/` directory.
